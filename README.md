# Nerf Floor Scanner

![thumbnail icon](media/thumbnail-small.png)

Do you feel the floor scanner is a bit OP?  

This mod disables the floor scanner and sets the projects related to the scanner to no cost.

# Add and Remove Safety
This mod is safe to add and remove at any time. 

Notes:
* If the player is currently in a mission, the changes may not show until back to the spaceship.  At worst, a floor will or will not be scanned.
* If the player purchased the scanner upgrades, they will remain purchased.
